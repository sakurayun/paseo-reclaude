# 新主题迁移逐页核对

日期：2026-11-02；执行者：Codex。

## 基准与结论

以 fork 迁移前 `db3bf650a94383d597b6250305478f28d1e77160`、`docs/new-theme.md` 和主题提交 `7864f7eef`、`814fbe46f`、`523de2fad` 为依据。保留新版工作区、分屏、插件和面板接口，恢复原有浮动外壳与无结构描边规则。

确认的主要回归不是配色定义丢失，而是主题使用处漏接：工作区 `centerCard` 样式存在，但新版 `SplitContainer` 未使用；标题也未传入外壳背景样式。仅检查主题注册表和编译无法发现此问题。本次将分屏树放入真实浮卡，标题保留在卡片外，并新增 JSX 挂载关系回归测试。

旧版本 11 套浮动配色的 13 个核心颜色字段及 shell 参数与迁移后的定义逐项比较一致。默认配色仍为 `auto`，系统浅色映射 `newTheme`、深色映射 `newThemeDark`；不将任何具体品牌配色推断为用户的本地偏好。
